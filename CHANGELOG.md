# Changelog

## 0.1.0 — 2026-08-21

### Added
- YasReady-branded standalone Publish shell.
- Local-only DOCX import.
- Direct Word XML extraction with exact paragraph text preservation.
- Chapter, text-message, scene-break, and Word-style classification.
- Read-only manuscript source inspector.
- Local project library using IndexedDB.
- SHA-256 source-file fingerprint and canonical manuscript Story Lock.
- Manual Story Lock re-verification.
- Parser / Story Lock unit tests.

### Explicitly not included
- Manuscript editing or rewriting.
- AI content changes.
- PDF/EPUB export.
- Pagination or typography controls.
- Cloud sync.
