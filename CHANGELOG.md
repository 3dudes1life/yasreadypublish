# Changelog

## 0.2.0 — Print Structure
- Added editable 6×9 print design layer.
- Added mirrored inside/outside margin model and long-book gutter warning.
- Added right-hand/odd chapter start logic and automatic blank versos.
- Added local structural pagination with oversized-paragraph splitting for preview only.
- Added two-page spread preview and page navigation.
- Added v0.1 project migration without changing source blocks.
- Story Lock is verified before pagination.
- Fixed static GitHub Pages CSS loading.


## 0.1.0 — 2026-08-21

### Added
- YasReady-branded standalone Publish shell.
- Local-only DOCX import.
- Direct Word XML extraction with exact paragraph text preservation.
- Chapter, text-message, scene-break, and Word-style classification.
- Read-only manuscript source inspector.
- Local project library using IndexedDB.
- SHA-256 source-file fingerprint and canonical manuscript Story Lock.
- Manual Story Lock re-verification.
- Parser / Story Lock unit tests.

### Explicitly not included
- Manuscript editing or rewriting.
- AI content changes.
- PDF/EPUB export.
- Pagination or typography controls.
- Cloud sync.
